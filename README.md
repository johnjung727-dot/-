# 환율 예측 프로젝트 (USD/KRW)

이 프로젝트의 목적은 **실시간 환율과 경제 뉴스, 국내외 정치 이슈를 종합**해 향후 약 **1주일~1개월** 범위의 USD/KRW 환율 흐름을 예측하는 것입니다. 현재는 초기 설계 단계이며, 데이터 수집·전처리·모델링·검증 계획을 문서화하고 향후 구현을 위한 기준을 제공합니다.

## 목표

- **실시간 환율** 및 거시 경제 지표를 활용한 단기(1주~1개월) 환율 흐름 예측
- 경제 뉴스/정치 이슈의 정성적 정보를 **정량 지표로 변환**해 모델 입력에 반영
- 모델 예측 결과와 **불확실성(신뢰 구간)** 을 함께 제공

## 핵심 데이터 소스(예시)

> 실제 구현 단계에서 API 키/라이선스/지연(latency) 조건에 따라 변경될 수 있습니다.

- 환율 시계열: 중앙은행/금융정보 API (예: 한국은행, FRED 등)
- 거시 지표: 금리, 인플레이션, 고용 지표 등
- 뉴스/정치 이슈: 국내외 언론 기사, 정책 발표, 지정학 이벤트
- 시장 심리: 옵션 내재변동성, 위험 프리미엄 지표 등

## 예측 파이프라인 설계 개요

1. **수집**
   - 환율 및 경제 지표의 실시간/일별 수집
   - 뉴스/정치 이슈 텍스트 데이터 수집
2. **정제/전처리**
   - 결측치 보정 및 이상치 처리
   - 타임스탬프 정렬/리샘플링
3. **특징 추출**
   - 텍스트 요약 및 감성/이벤트 임팩트 스코어링
   - 경제 지표의 변동률 및 이동 평균 파생
4. **모델링**
   - 시계열 예측 모델 + 뉴스/이슈 피처 결합
   - 불확실성 추정(예: 분위수 회귀, MC Dropout)
5. **검증 및 리포팅**
   - 백테스트/워크 포워드 검증
   - 예측 결과와 신뢰 구간 제공

## 향후 구현 계획(초안)

- [ ] 데이터 소스 확정 및 수집 스크립트 작성
- [ ] 뉴스/정치 이슈 텍스트 파이프라인 설계
- [ ] 모델 후보군 선정 및 기준 실험
- [ ] 예측 리포트 템플릿 제작
